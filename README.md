# Happy Birthday Masuma

A small, animated birthday webpage created by asadurrahmanshohag-tech.

This repository contains a single `index.html` that shows a Bengali birthday card with animations, music, and embedded media.

Notes:
- The page references Google Drive and external CDN assets (images/videos/audio). Make sure those links are publicly shared if you want visitors to see them.

How to view locally:
1. Clone the repo:

   git clone https://github.com/asadurrahmanshohag-tech/happy-birthday-masuma.git
2. Open `index.html` in your browser.

To publish with GitHub Pages:
1. Go to the repository Settings → Pages.
2. Under Source select the `main` branch and `/ (root)` folder, then Save.
3. Wait a minute and your site will be available at `https://asadurrahmanshohag-tech.github.io/happy-birthday-masuma/` (or the URL shown in the Pages settings).

If you want, I can enable GitHub Pages for you and adjust media to be hosted inside the repo so everything works offline.
